% ===== Mở đầu mục 3 — Tổng quan pipeline (≈ 0,5 trang) =====
% Viết gì: sơ đồ, hợp đồng dữ liệu giữa các khối, bảng chương học phần. Người: Hiếu.
Pipeline gồm bốn khối nối tiếp (Hình~\ref{fig:pipeline}), theo khung Dữ liệu $\to$ Tiền xử lý $\to$ Xử lý chính $\to$ Hậu xử lý $\to$ Đánh giá của học phần.
Các khối trao đổi dữ liệu qua hợp đồng chung \texttt{code/src/common/contracts.py}:
khung bao dạng $[x_0,y_0,x_1,y_1]$ (pixel) và lớp thuộc sáu lớp VAIPE.
\begin{enumerate}[label=(\Alph*)]
  \item Tiền xử lý: ảnh BGR $\to$ ảnh đã nắn, chỉnh nghiêng, khử bóng, khử nhiễu, tăng tương phản. Mỗi bước bật/tắt được.
  \item Phát hiện: ảnh $\to$ danh sách vùng chữ (khung, lớp, độ tin cậy).
  \item Nhận dạng: điền chữ và độ tin cậy cho từng vùng.
  \item Ghép khoản (hậu xử lý): danh sách vùng $\to$ bản ghi \texttt{PrescriptionResult} (JSON).
\end{enumerate}
Mỗi khối có một phương pháp đối chứng; toàn pipeline được đối chứng với mô hình thị giác--ngôn ngữ (VLM) zero-shot.
